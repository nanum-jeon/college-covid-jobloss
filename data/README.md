# data/

This folder is intentionally empty. No NLSY97 data are included in this repository.

Download the data from NLS Investigator (https://www.nlsinfo.org/investigator) and
place the files here with the following names/structure:

| Path in `data/` | Contents |
|---|---|
| `college_covid_jobloss/college_covid_jobloss.R` (+ its `.dat`) | Main NLSY97 extract (NLS Investigator R tagset) |
| `nlsy97_covid_displacement/nlsy97_covid_displacement.R` | NLSY97 Round 20 job-separation variables |
| `nlsy97_covid_supplement_displacement/nlsy97_covid_supplement_displacement.R` | NLSY97 COVID-19 supplement variables |
| `covid_job_disruption/covid_job_disruption.R` | COVID-19 employment-disruption variables |
| `nlsy97_GED/nlsy97_GED.R` | GED / educational attainment variables |
| `nlsy97_interviewer_id/nlsy97_interviewer_id.R` | Interviewer IDs |
| `customweight_nlsy97_any.dat` | NLSY97 custom weights (NLS custom weighting program) |
| `edurose97_socioeconomicoutcomes_20211226.dta` | Pre-processed NLSY97 socioeconomic outcomes file |
| `CPIAUCSL.csv` | CPI-U series (FRED, CPIAUCSL) |
| `face_remote_values.csv` | O*NET-based face-to-face / remote-work occupation scores |
| `2002_coc_soc_crosswalk.csv` | 2002 Census occupation code to SOC crosswalk |
